## Typography system

- Display (hero `h1` only): `font-sans` with strong weight (`font-extrabold`), tight tracking (`tracking-tight`), and tight leading (`leading-tight`).
- Heading (`h2` and major section titles): `font-sans` with `font-extrabold`, `tracking-tight`, and `leading-tight` for consistent scanability.
- Subheading (`h3` and card headings): `font-sans` with `font-semibold` (or `font-bold` where extra emphasis is needed).
- Body/UI copy: `font-sans`; utility/meta labels can continue using `font-mono`.
- Serif display is not a default heading style. If used in future, keep it as a rare, intentional accent only.
